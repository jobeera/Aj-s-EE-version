# ExtraaEdge EduMartech Live Prototype

## Local preview
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Create a free Vercel account.
2. Choose **Add New → Project**.
3. Import this folder from GitHub, or upload it through a Git repository.
4. Vercel detects Vite automatically.
5. Build command: `npm run build`
6. Output directory: `dist`
